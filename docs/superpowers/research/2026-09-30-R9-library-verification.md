## 2) Bun 1.4 API facts (bun.com/docs)

- **WebSocket** (`/api/websockets`): `server.upgrade(req, { headers?, data? }): boolean`; handlers `open(ws)`, `message(ws, msg)`, `close(ws, code, reason)`, `drain(ws)`, `error(ws, err)`; `ws.subscribe(topic)`, `ws.unsubscribe`, `ws.isSubscribed`, `ws.publish(topic, data, compress?)`, `server.publish(topic, data, compress?)`; `ws.send()` → `-1` enqueued (backpressure), `0` dropped, `>0` bytes sent; options `idleTimeout` (default 120 s), `maxPayloadLength` 16 MB, `backpressureLimit` 16 MB, `closeOnBackpressureLimit` false, `sendPings` true, `publishToSelf` false, `perMessageDeflate` false.
- **HTTP/static** (`/api/http`, `/blog/bun-v1.4`): `routes` (≥1.2.3): static `Response`, `"/api/*"` wildcards, `"/users/:id"` params, per-method objects, HTML imports (`import index from './index.html'`), directory routes `"/static/*": { dir: "./public" }` (1.4: sendfile, ETag/Last-Modified/304/Range), `fetch` fallback; `port: 0` → `server.port`, `server.url`; HTTP `idleTimeout` default 10 s (max 255, 0 = off); `server.reload()`, `server.stop(true)`; `unix:` sockets.
- **Compile** (`/bundler/executables`): `bun build --compile ./index.ts --asset ./public --outfile app` embeds a file or directory keeping filenames, read via `path.join(import.meta.dir, …)`/`Bun.file`; 1.4 makes `/$bunfs/` a real tree for `existsSync/statSync/readdirSync`; `Bun.embeddedFiles`; `--bytecode` now supports `--format=esm` (requires `--compile`); `--target bun-{linux,darwin,windows}-{x64,arm64}` (+`-musl`); `--minify`, `--sourcemap`, `--windows-icon`, `--windows-hide-console`, `--compile-exec-argv`; SQLite embed `with { type: 'sqlite', embed: 'true' }`.
- **Spawn** (`/api/spawn`): `Bun.spawn(cmd, { cwd, env, stdin, stdout, stderr, stdio, onExit, signal, timeout, killSignal, maxBuffer, ipc, serialization, windowsHide, argv0, terminal })`; stream values `"pipe" | "inherit" | "ignore" | Bun.file() | number | null`; piped `proc.stdout/stderr` are `ReadableStream` (`for await (const chunk of proc.stdout)`), `proc.stdin` is a `FileSink` (`write/flush/end`); `pid`, `exited`, `exitCode`, `signalCode`, `killed`, `kill(sig?)`, `ref/unref`, `resourceUsage()`; `Bun.spawnSync` → `success`, `Buffer` output.
- **bun:sqlite** (`/api/sqlite`): `new Database(path, { readonly, create, strict, safeIntegers })`; `db.query()` (cached) vs `db.prepare()`; `.all/.get/.run/.values/.iterate`, `.as(Class)`; `db.transaction()` (`.deferred/.immediate/.exclusive`, nested = savepoints); `db.run("PRAGMA journal_mode = WAL")`; `serialize()/deserialize()`, `loadExtension`.
- **bun test** (1.4): `--parallel[=N]`, `--isolate`, `--shard=M/N`, `--timings`, `--changed`. Node compat: `node:sqlite` 100 %, `node:util` "Fully implemented".
- **Git commands to spawn** (git-scm.com): `git worktree add <path> <branch>` — if `<branch>` is missing locally "but there does exist a tracking branch in exactly one remote … treat as equivalent to `git worktree add --track -b <branch> <path> <remote>/<branch>`" (so a worktree for a not-yet-checked-out remote branch works in one command); `-b/-B`, `--detach`, `--orphan`, `--lock`; a branch checked out elsewhere is refused unless `--force`; `git worktree list --porcelain` (`worktree`, `HEAD`, `branch`, `detached`, `locked [reason]`, `prunable`); `remove [--force]` (twice for locked), `prune [--expire]`, `lock/unlock`, `repair`. Default branch: `git ls-remote --symref origin HEAD` → `ref: refs/heads/main\tHEAD`.

## 4) Test-runner decision for Bun-only packages

Vitest 5.0.3 requires Node ≥22.12 and Vite ≥6.4; its docs mention Bun only as a package manager ("use `bun run test` instead of `bun test`"). Running Vitest on the Bun runtime is unsupported in practice: issues #5551 (closed "not planned"), #9031 (module mocking broken under Bun), #10359, #10590 (closed "not planned", 2026-06). `bun:sqlite` is a Bun-only builtin, so a Node-hosted Vite worker cannot import it. **Decision:** `bun test` for `daemon`/`shared` packages that touch `bun:sqlite`, `Bun.serve`, `Bun.spawn`; Vitest 5 (Browser Mode) only for the React/PixiJS client; keep schemas and the simulation runtime-agnostic so either runner can execute them.

Pipeline: `aseprite -b file.ase --sheet out.png --data out.json --format json-hash --sheet-type packed --list-tags --filename-format '{title}_{tag}_{tagframe}'` (also `--trim`, `--merge-duplicates`, `--inner/--shape/--border-padding`). Pixi's `Spritesheet` reads `frames` + top-level `animations` + `meta` only; Aseprite writes tags to `meta.frameTags`, so a build step must map `frameTags` → `animations`. Tiled is 1.12.2 (2026-05-27), not 1.11; JSON `layers[].type` ∈ `tilelayer|objectgroup|imagelayer|group`, `data` csv/base64 (+zlib/gzip/zstd), `chunks` for infinite maps, external tileset `source` (.tsj) + `firstgid`, flip flags `0x80000000/0x40000000/0x20000000/0x10000000`. Pixel-perfect PixiJS 8: `TextureSource.defaultOptions.scaleMode = 'nearest'`; `Application.init({ roundPixels: true, antialias: false, resolution: devicePixelRatio, autoDensity: true })`; integer `scale` on the world container.

Browser: `Notification.requestPermission()` → `'granted'|'denied'|'default'`, call from a click, secure context; iOS/iPadOS only for Home-Screen web apps (16.4+), mobile needs service-worker notifications. `navigator.setAppBadge(n)`/`clearAppBadge()` only for installed PWAs (Chrome/Edge ≥81; iOS 16.4 Home-Screen apps; MDN "limited availability", no Firefox) → keep a `document.title` counter fallback. Web Audio: an `AudioContext` created before a gesture is `suspended`; call `ctx.resume()` in a click handler (Chrome ≥71 policy). `navigator.clipboard.writeText()`: Chrome 66/Firefox 63/Safari 13.1, secure context (localhost counts), rejects with `NotAllowedError`.

Paraglide (paraglidejs.com): `paraglideVitePlugin({ project: './project.inlang', outdir: './src/paraglide' })` (or `project.inlang/paraglide.config.js` with `outdir`, `emitTsDeclarations`); `import { m } from './paraglide/messages.js'; m.greeting({ name })`, per-call `{ locale: 'cs' }`; runtime `getLocale/setLocale/locales/baseLocale/isLocale/overwriteGetLocale/overwriteSetLocale`; strategy default `["cookie","globalVariable","baseLocale"]`, use `["localStorage","cookie","preferredLanguage","baseLocale"]` for a URL-less SPA (key `PARAGLIDE_LOCALE`); `setLocale()` reloads the document unless `{ reload: false }` (then re-render via your own React state). Format is inlang's own (MessageFormat-2-inspired, not ICU 1): `{name}`, variants via `declarations/selectors/match` using `Intl.PluralRules` categories (Czech `few/many/other` automatic). Claim: "up to 70% smaller … 47 KB vs 205 KB for 5 locales and 200 messages".

LogTape (logtape.org): `bun add @logtape/logtape`; `configure({ sinks, filters, loggers: [{ category, lowestLevel, sinks, filters }], reset })`, `configureSync`, `reset()`, `dispose()`; sinks `getConsoleSink`, `getStreamSink(WritableStream)`, `@logtape/file` `getFileSink`/`getRotatingFileSink` (maxSize, maxFiles, buffering, `nonBlocking`), `fingersCrossed()`, `fromAsyncSink()`, `withFilter(sink, level|fn)`; formatters `jsonLinesFormatter`/`getJsonLinesFormatter`, `ansiColorFormatter`; `@logtape/redaction` `redactByField` (`DEFAULT_REDACT_FIELDS`), `redactByPattern` (`EMAIL_ADDRESS_PATTERN`, `CREDIT_CARD_NUMBER_PATTERN`, `JWT_PATTERN`), `createHmacPseudonymizer`. `--debug` switching: re-run `configure({ …, reset: true })` or a filter closing over a mutable level (no dedicated runtime API documented).
